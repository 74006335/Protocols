Fully Homomorphic Encryption

Compute on encrypted data without ever decrypting it

A revolutionary encryption scheme that preserves privacy while enabling computation on sensitive data

Explore FHE

What is Fully Homomorphic Encryption?

Definition

FHE allows computations on encrypted data, producing encrypted results that match operations on plaintext when decrypted.

History

First proposed in 1978, the first working FHE scheme was developed by Craig Gentry in 2009, winning him a MacArthur "Genius Grant".

Key Advantage

Enables secure outsourcing of data processing to untrusted servers while maintaining complete data privacy.

How FHE Works

1

Encrypt

Data is encrypted before leaving the client

→
2

Compute

Operations performed on encrypted data

→
3

Return

Encrypted results sent back to client

→
4

Decrypt

Client decrypts final results only

Addition Supported

Enc(A) + Enc(B) = Enc(A+B)

Multiplication Supported

Enc(A) × Enc(B) = Enc(A×B)

Unlimited Operations

Both operations can be performed repeatedly
